# Plugin.Uno.MVVMExpress.Templates

`dotnet new` templates for **Plugin.Uno.MVVMExpress**.

```bash
dotnet new install Plugin.Uno.MVVMExpress.Templates
dotnet new uno-mvvmexpress -n MyApp
dotnet new uno-mvvmexpress-page -n Catalog --namespace MyApp
```

This is not Plugin.Maui.MVVMExpress.Templates. There is no Shell — use a `Frame` named `NavigationHost`.

NuGet: https://www.nuget.org/packages/Plugin.Uno.MVVMExpress.Templates
GitHub: https://github.com/nuvyntralabs/Plugin.Uno.MVVMExpress
